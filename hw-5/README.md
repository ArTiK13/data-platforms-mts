# Домашнее задание №5: Prefect

Нужны выполненные ДЗ №1–4, SSH-доступ к edge через `data-platforms-course` и `sudo` без пароля у `team`.

Запуск из корня репозитория:

```bash
bash hw-5/deploy.sh
```

Скрипт устанавливает Prefect 3.9.3 и запускает `flow.py`. Поток вызывает готовый `~/hw4-spark/run.sh` из ДЗ №4: Spark на YARN читает CSV из HDFS, приводит типы, переводит события в верхний регистр и считает события и уникальных пользователей по дате и типу события. Результат перезаписывается в таблицу Hive `hw4.event_stats` в формате Parquet.

В конце потока запускается проверка из ДЗ №4. Ожидаются две партиции, пять строк и статус YARN `SUCCEEDED`.

Повторный запуск потока:

```bash
ssh data-platforms-course 'bash ~/hw5-prefect/run.sh'
```
