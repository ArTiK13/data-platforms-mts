# Практическое задание №1 - HDFS-кластер

Скрипты устанавливают Hadoop 3.4.2 на четыре машины.

| Машина | Службы HDFS |
|---|---|
| `namenode` (`team-08-nn`) | NameNode и SecondaryNameNode |
| `data-platforms-course` (`team-08-en`) | DataNode |
| `datanode-0` (`team-08-00`) | DataNode |
| `datanode-1` (`team-08-01`) | DataNode |

После установки в кластере работают три DataNode. Для файлов задано три реплики.

## Пользователь и SSH

На каждой машине скрипт создаёт пользователя `hadoop` со случайным паролем. Пользователь не входит в группу `sudo`, а процессы Hadoop работают от его имени.

Edge подключается к внутренним узлам с ключом `~/.ssh/team_internal`. Скрипты обращаются к узлам через имена `namenode`, `datanode-0` и `datanode-1` из SSH-конфигурации пользователя `team`.

Пароль лежит в локальном файле `hw-1/.cluster-password`.

## Как работают скрипты

1. На локальной машине запустите `deploy.sh`. Он создаёт пароль, копирует файлы на edge и запускает следующий скрипт.
2. `edge-deploy.sh` скачивает Hadoop и передаёт установочные файлы на остальные машины по готовым SSH-подключениям. Затем он настраивает узлы и проверяет кластер.
3. `node-setup.sh` устанавливает Java 17 и Hadoop на одну машину. В зависимости от аргумента он настраивает NameNode с SecondaryNameNode или DataNode.
4. `check.sh` проверяет готовый кластер.

Последовательность запуска:

```text
deploy.sh
  edge-deploy.sh
    node-setup.sh на четырёх машинах
      check.sh
```

## Запуск

Из корня репозитория выполните:

```bash
bash hw-1/deploy.sh
```

При первом запуске скрипт скачает около 1 ГиБ. Установка займёт несколько минут.

## Проверка

После установки `edge-deploy.sh` автоматически запускает `check.sh`. Проверочный скрипт смотрит:

- пароль и отсутствие `sudo` у пользователя `hadoop`;
- доступ с edge к внутренним узлам по готовому SSH-ключу;
- работу NameNode, SecondaryNameNode и трёх DataNode;
- запись и чтение файла с тремя репликами;
- веб-интерфейс NameNode.

Проверку можно повторить отдельно:

```bash
ssh data-platforms-course 'bash ~/hw-1-hdfs/check.sh'
```

## Веб-интерфейс NameNode

Запустите SSH-туннель на локальной машине:

```bash
ssh -N -L 9870:team-08-nn:9870 data-platforms-course
```

После этого откройте [http://localhost:9870](http://localhost:9870). На странице Datanodes должны быть три работающих узла и ни одного недоступного.
