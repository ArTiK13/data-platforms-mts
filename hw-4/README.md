# Домашнее задание №4: Spark на YARN

На edge (`team-08-en`) запускаем Spark 4.1.3 на YARN из [ДЗ №2](../hw-2). Обрабатываем события из HDFS и сохраняем результат как таблицу для Hive из [ДЗ №3](../hw-3).

## Запуск

Нужны работающие ДЗ №1–3 с загруженными CSV, SSH-доступ к `team@2.59.83.169`, sudo без пароля и доступ в интернет на edge.

Запуск на своём компьютере из корня репозитория:

```bash
bash hw-4/deploy.sh
```

Скрипт копирует файлы в `~/hw4-spark` на edge, устанавливает Spark, запускает обработку и проверку.

## Обработка данных

Повторный запуск обработки:

```bash
ssh team@2.59.83.169 'bash ~/hw4-spark/run.sh'
```

`run.sh` запускает `job.py` от hadoop на YARN. В одной SparkSession с поддержкой Hive читаем CSV из `hdfs://team-08-nn:8020/user/hive/external/hw3/events`

Приводим `user_id` к INT, `dt` к DATE, переводим тип события в верхний регистр. По дате и типу считаем события и уникальных пользователей

Через `saveAsTable` сохраняем внешнюю таблицу `hw4.event_stats` в Parquet с партициями по `dt`. Повторный запуск перезаписывает результат

## Проверка

```bash
ssh team@2.59.83.169 'bash ~/hw4-spark/check.sh'
```

Через Beeline читаем таблицу и сравниваем две партиции и пять строк с `data/expected.tsv`, выводим список файлов в HDFS. У приложения в YARN должны быть статусы State: FINISHED, Final-State: SUCCEEDED.
